# LaptopsAnytime — Higher Education AEO Demo

A demonstration page at `/higher-education` showing what one new,
buyer-focused AEO (Answer Engine Optimization) page could look like added to
the existing [laptopsanytime.com](https://laptopsanytime.com) — built to be
visually consistent with their live site, not a redesign of it. Targets
university IT and library leadership.

This is a prototype for client review only: it is `noindex, nofollow` and
must never be confused with LaptopsAnytime's actual website.

See [docs/superpowers/specs](docs/superpowers/specs) for the design spec and
[docs/superpowers/plans](docs/superpowers/plans) for the implementation plan.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000/higher-education](http://localhost:3000/higher-education).

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm test` — run the test suite (Vitest + React Testing Library)
- `npm run lint` — lint
